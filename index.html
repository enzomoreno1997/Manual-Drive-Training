Gusto kong gumawa ng isang 2D top-down o side-scrolling driving game na naka-host sa GitHub Pages. HTML5, CSS, at vanilla JavaScript lang ang gagamitin para madaling i-deploy. ​Ito ang pinaka-espesyal na feature: Gusto ko may Manual Transmission Mechanic. Kailangan may clutch at gear shifting (Neutral, 1st to 5th gear, Reverse). Kapag hindi tumugma ang RPM sa gear o binitiwan nang bigla ang clutch habang mataas ang RPM, dapat mag-stall (mamatay) ang makina o umusad nang pautal-utal (jerking effect). ​Iba pang requirements: ​Controls: Keyboard controls (halimbawa: W/S para sa gas/preno, A/D para sa steering o lane change kung top-down, Shift para sa clutch, at 1-5/N/R para sa pagpapalit ng gear). Maglagay din ng on-screen buttons para sa mobile/touch users kung sakali. ​Dashboard UI: Magpakita ng real-time Speedometer, Tachometer (RPM gauge na may redline warning), current gear indicator, at clutch engagement status. ​Gameplay / Environment: Simple obstacle dodging (mga sasakyan o lubak sa daan) para maramdaman ang challenge ng pagtimon ng manual car. May score o distance tracker din. ​Code Structure: Pwede mo bang ibigay sa akin ang kumpletong code sa isang malinis na single-file HTML (kasama na ang CSS at JS sa loob) para madali ko siyang ma-copy paste at i-upload sa GitHub repository ko?
